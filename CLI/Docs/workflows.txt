Configure:
StonebotCLI run
StonebotCLI config load
StonebotCLI config set (--twitch-id=<clientId>) (--twitch-secret=<clientSecret>) (--twitch-user=<botUsername>) (--twitch-channel=<broadcasterChannel>)

Twitch connect:
StonebotCLI run
StonebotCLI config load
StonebotCLI twitch auth
StonebotCLI twitch config
StonebotCLI twitch run

Twitch disconnect:
StonebotCLI twitch stop
StonebotCLI stop
